# Agent trace policy

The test requires the real agent conversation verbatim. A trace is therefore captured from the actual session rather than reconstructed as a narrative after the work.

Verbatim does not mean secrets should be pasted and redacted later. Keep API keys in environment variables, refer to their variable names in prompts, and avoid including private audio transcripts or unrelated personal data in agent messages and tool output. Before submission, scan the export for credential patterns and personal data; if anything must be removed, disclose the redaction explicitly rather than presenting the result as untouched.

The trace is exported at submission time and is not committed to this public repository until its
privacy review is complete.
